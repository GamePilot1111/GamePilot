# GamePilot Live Vision 1.3 — Live Grid / карта зі змінним масштабом

## Що додано

- **F5** або **«Сітка на грі»** в головному вікні: показує/ховає прозорий шар над вибраним монітором.
- Сітка у світових *відносних* координатах. Поки персонаж рухається, сітка переміщується разом зі світом, а не залишається приклеєною до монітора.
- На сітці: автоматично виявлені T1 із оцінкою схожості, раніше збережені ресурси, вручну підтверджені позначки. `?` означає непідтверджений ресурс.
- Міні-карта у правому верхньому куті сітки: пройдені клітинки (зелений), непрохідні (сірий), виходи (червоний), ресурси (жовтий), база (синій), персонаж (бірюзовий). Масштаб обчислюється за розмірами відомої частини карти.
- Вкладка **Карта**: «Автомасштаб / пройдена територія». Зі зростанням дослідженої області масштаб поступово зменшується, щоб умістити всю відому частину. Повзунок дозволяє перейти до ручного масштабу.
- Під час запуску оверлей **вимкнений**; користувач вмикає його окремо. Автоматичне керування також не вмикається без дозволу.

## Використання

1. Зібрати Windows EXE через `.github/workflows/build-windows.yml` або встановити Python 3.11 і `pip install -r requirements.txt`, запустити `python main.py`.
2. Запустити тестовий клієнт на обраному моніторі. У GamePilot навчити шаблон каменя T1 на вкладці «Живий екран». Без шаблону автоматичні T1 не з'являться, але вручну навчена карта відображатиметься.
3. Натиснути «Сітка на грі: OFF / F5» або F5. Відкрити гру, пересуватися: позначки T1 і клітинки прив'язуються до оціненого положення у локальній карті.
4. Для контрольованого навчання увімкнути «Навчання маршруту», пройти маршрут вручну; F7 позначає камінь, F9 перешкоду, F10 заборонений вихід, F11 прохід.
5. Перейти на вкладку «Карта», увімкнути «Автомасштаб», перевірити пройдену територію, ресурси, збережені виходи.

## Обмеження, важливі для достовірності

- **Це не точні координати сервера.** Програма оцінює положення за відносним зсувом кадрів. Довге пересування, повторювані текстури, телепортація й різкі зміни масштабу можуть призвести до дрейфу. Для переприв'язки поверніться на базу та натисніть «Я на базі».
- Накладення не має перекривати знімки екрана, інакше розпізнавання побачить власну сітку та може давати хибні результати. Для цього Windows використовується `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` (Windows 10 версія 2004 або новіша). Якщо підтримки немає, оверлей **не вмикається**, а карта й сітка у вкладках залишаються доступними.
- На комп'ютерах з кількома моніторами та неоднаковими DPI/масштабуванням може знадобитися налаштування геометрії. Рекомендується 100% або однаковий масштаб дисплеїв.
- Зміна масштабу вікна гри/камери, зміна роздільності або переміщення вікна потребує повторної калібровки.
- Сітка і міні-карта не доводять, що клітинка прохідна; вони лише відображають те, що вже вивчено.
- Систему перевірено **автоматичними Python-тестами**, але запуск оверлея поверх реального Windows-клієнта в цьому середовищі не перевірено.

## Безпека

Оверлей пропускає кліки до гри (`WA_TransparentForMouseEvents` + `WS_EX_TRANSPARENT`) і не повинен перехоплювати фокус. F8 залишається аварійною зупинкою керування. Заборона виходів зберігається.
