# GamePilot Live Vision — як запустити

## Якщо на Windows немає Python

1. Розпакуй ZIP, завантаж папку проєкту в свій GitHub-репозиторій (разом із прихованою `.github/workflows/build-windows.yml`).
2. Відкрий вкладку **Actions → Build Windows EXE → Run workflow**.
3. Після успішного завершення завантаж артефакт **GamePilot_LiveVision_Windows**.
4. Розпакуй його й запускай **GamePilot_LiveVision.exe** (файли поруч не видаляти).

Windows EXE не входить до вихідного ZIP: його створить GitHub Actions.

## Початкове налаштування

1. Запусти програму та переконайся, що видно гру в розділі **Живий екран**.
2. Виділи прямокутником зображення одного каменя T1 (обери `Камінь T1`).
3. Наведи курсор на камінь у грі, щоб з'явилася назва, і виділи `Назва в підказці при наведенні`.
4. Під час ручного збору виділи прямокутник `Індикатор збору` з видимою зеленою смугою.
5. У вкладці **Карта** познач усі помітні виходи та перешкоди.
6. Параметри змінюються у вкладці **Адмін-панель**. Вкажи 4 камені й перевір час відновлення.
7. Тільки після цього увімкни прапорець `Дозволити автоматичні кліки` та натисни **ПОЧАТИ**.
8. **F8 — аварійна зупинка**.

## Що вже працює

Живий потік, розпізнавання за вибраними шаблонами, перевірка підказки, відносна карта, редактор перешкод/виходів, маршрутизатор A*, журнал, збереження, система станів для експериментального автоматичного збору, аварійна зупинка.

## Що ще не гарантується

Автоматичне впізнавання річок і виходів, точна SLAM-карта, безпомилковий обхід перешкод та збір на будь-якій локації. Ці частини потребують відеозаписів і тестів у твоєму клієнті. Не запускати без нагляду до калібрування та перевірки.


## Оновлення 1.1: стабільність

- Керування не працює без заданої назви активного вікна тестового клієнта.
- Навігація перевіряє шлях кліка по карті, а не тільки кінцеву точку.
- Невдалі напрямки дослідження тимчасово відкладаються.
- Для Windows-збірки налаштовано запуск усіх тестів через `pytest`.

**Важливо:** повна автономність без калібрування і перевірки на твоєму клієнті не гарантована. Виходи і непрохідні зони перед запуском автокерування потрібно перевірити на карті.
